# Qodirov Shoxrux — shaxsiy sayt

🔗 **https://qodiroff2008.github.io/**

Dasturlashni noldan o'rganish jarayonida yaratilgan shaxsiy saytim.
Hech qanday tayyor shablonsiz — sof HTML, CSS va JavaScript.

## Imkoniyatlar

- Kunduzgi va tungi rejim (qurilma sozlamasiga moslashadi, tanlovni eslab qoladi)
- Telefon uchun pastdan chiqadigan menyu
- Klaviatura va ekran o'quvchi dasturlar uchun qulaylik (WCAG 2.2)
- AVIF/WebP rasmlar va saytning o'zida saqlanadigan shriftlar — tez yuklanish
- Open Graph, JSON-LD — ulashish va qidiruv tizimlari uchun

## Tuzilma

| Fayl | Vazifasi |
|---|---|
| `index.html` | Sahifa tuzilmasi va matn |
| `style.css` | Dizayn tizimi (tokenlar) va uslublar |
| `script.js` | Rejim, menyu, animatsiyalar, nusxalash |
| `404.html` | "Sahifa topilmadi" sahifasi |
| `fonts/` | Inter va Lora shriftlari |
